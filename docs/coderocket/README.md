# CodeRocket documentation

CodeRocket is a standalone website-cloning product. It contains only the source-import, private
Studio, guided editing, connections, versioning, billing, and publishing paths.

- [Product principles](./product-principles.md)
- [Website builder architecture](./site-builder-architecture.md)
- [Operations](./operations.md)

The internal plan IDs are `free`, `solo`, and `agency`; customer labels are Free, Launch, and Studio.
All product tables and functions use the isolated `cr_*` namespace.
